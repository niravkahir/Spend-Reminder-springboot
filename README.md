# 💰 Spend Remainder

A full-stack expense management application built using **Spring Boot** and **React.js** to help users track daily expenses, manage budgets, analyze spending patterns, and make smarter financial decisions. The application features secure authentication, expense tracking, budget management, interactive dashboards, and AI-powered financial insights.

## 🌐 Live Demo

- **Frontend Application:** [https://spend-reminder.vercel.app](https://spend-reminder.vercel.app)

*Note: The backend is hosted on Render's free tier and may take approximately 50 seconds or longer to wake up after inactivity.*

## ✨ Features

- **Authentication:** Secure user registration and login with JWT-based authentication.
- **Expense Management:** Add, view, update, and delete personal expenses.
- **Dashboard:** Interactive dashboard displaying expense summaries and financial statistics.
- **Category Management:** Organize expenses into different categories for better tracking.
- **Budget Management:** Set and manage budgets to monitor spending and maintain financial discipline.
- **Expense Analytics:** Visualize spending patterns through interactive charts and monthly reports.
- **AI-Powered Insights:** Generate intelligent financial insights and analyze historical spending patterns.
- **Expense Forecasting:** AI-powered predictions of upcoming monthly expenses based on previous spending data.
- **Personalized Recommendations:** Receive AI-generated suggestions to improve spending habits.
- **Responsive Design:** User-friendly interface optimized for desktop and mobile devices.
